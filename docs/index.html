Descripción

API REST con Flask y SQLite que permite registrar usuarios (con contraseñas hasheadas), iniciar sesión y acceder a una página de bienvenida. Incluye un cliente de consola.

Endpoints

POST/loginVerifica credenciales e inicia sesión

Respuestas conceptuales

¿Por qué hashear contraseñas?

Para que, si la base de datos se filtra, las contraseñas no queden expuestas. El hash es una función de un solo sentido (no se puede revertir), y con salt y algoritmos lentos como scrypt o bcrypt se dificultan los ataques de fuerza bruta. Al iniciar sesión se compara el hash de lo ingresado con el guardado, sin necesidad de conocer la contraseña real.

Ventajas de usar SQLite en este proyecto

  • No requiere instalar ni configurar un servidor de base de datos.
  • Toda la base es un único archivo, fácil de copiar y entregar.
  • Viene incluida en Python (módulo sqlite3).
  • Los datos persisten aunque se reinicie el servidor.
  • Soporta SQL estándar y transacciones; es suficiente para un proyecto de este tamaño.
